📋 Architecture Overview

This interactive documentation represents the complete source code architecture of the Propulsion game, analyzed from 65+ TypeScript/JavaScript files across the /src/ directory.

🚀 Entry Point System

  • main.ts: Application entry point and initialization
  • engineBootstrap.ts: Core engine setup and configuration

⚙️ Core Engine Systems

  • SceneManager: Manages scene transitions and lifecycle
  • World: Contains and manages the game world state
  • LevelManager: Handles level progression and state
  • WorldBounds: Defines game world boundaries

🎮 Game Systems

  • GameScene: Main game loop and gameplay logic
  • GameController: Orchestrates all game systems
  • CollisionDetection: Handles collision detection and response
  • EventManager: Manages game events and communication

🎭 Actor System

  • ActorManager: Manages all game actors lifecycle
  • ActorFactory: Factory pattern for creating actors
  • Actor Hierarchy: BaseActor → ShipActor, BallActor, TurretActor, etc.

🔄 Key Architectural Patterns

  • Factory Pattern: ActorFactory creates different types of game actors
  • Inheritance Hierarchy: Actor → BaseActor → Concrete actors
  • Composition: ShipActor contains TractorBeam and Kinematics
  • Observer Pattern: EventManager handles game events
  • Component System: Modular actor components for reusability
