These instructions are intended for the AI to generate Propulsion level maps:

1. A tile and an object is 128x128 pixels
2. A coordinate on the map = tile(X,Y) x tile size
3. An object position is always next to a tile, as an object must be built on such tile.
4. The rotation of an object is following the fact that the underside of an object must be attached to a ground tile
5. A level must be at least 32 x 50 tiles
6. The ship must be 3 tiles above the ground level


Common:
- Take a look at level 1 to level 3 to understand the setup
